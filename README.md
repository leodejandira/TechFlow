# TaskMind - Sistema de Gerenciamento Ágil de Tarefas

## Objetivo
Sistema desenvolvido para startup de logística gerenciar fluxo de trabalho em tempo real usando metodologias ágeis.

## Escopo do Projeto
- CRUD completo de tarefas
- Sistema de priorização  
- Status tracking em tempo real
- API RESTful

## Metodologia
**Kanban + Scrum** com quadros visuais e sprints de 1 semana

## Como Executar
```bash
pip install -r requirements.txt
python src/main.py
```
